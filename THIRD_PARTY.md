# Bundled components

- **GWAu3**: API source under Runtime/API, from the locally supplied GWAu3 project. Its bundled updater configuration identifies [JAG-GW/GwAu3](https://github.com/JAG-GW/GwAu3) as the upstream repository. Automatic updating is disabled for reproducible test builds.
- **AutoIt ImGui wrapper**: Runtime/ImGui/ImGui.au3 retains its original author credit to **thedemons**. The accompanying imgui.dll and utility file were supplied with the existing GWAu3 setup.
- **Bergen route and build**: adapted from the project author's original GWA2 Bone Farmer 55HP Monk script.

Bundled components retain their original notices. No new license is assigned to third-party components by this repository.
